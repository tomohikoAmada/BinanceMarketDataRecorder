# M2.2 独立复核与实施记录（2026-11-02）

> **再次独立复核结论**：`5afcb40` 的零空分片与首分片标记实现符合计划主体要求，但重连分类存在一个可复现的判定顺序错误。本轮已用最小修改修复，并补充新旧产物混合规范化/回放和单一 Catalog 启动事件的直接验证。下文原实施记录保留，最终复核结果见文末。

## 复核结论与范围

本轮工作针对 [`docs/production_milestone_plan.md`](../production_milestone_plan.md) 中的任务 **`M2.2`：取消启动时每流 0 记录空 `.zst` 分片（更新 `ADR-0038`）** 进行实施与独立复核。

目标是彻底移除每次采集进程启动时为数十/上百个流写入 0 记录空 `.zst` 分片和 `.json` manifest 的过度防御行为，消除服务重启时的文件与 `fsync` 风暴，同时保持对进程边界、重连分界和数据完整性的严格检验与回放兼容。

| 重连分界判定兼容 | [`audit/reconnect_boundaries.py`](../../src/binance_market_data_recorder/audit/reconnect_boundaries.py) 原依赖 0 记录空分片识别进程边界，否则新旧连接跳变会误报为 `UNMARKED_RECONNECT`。 | 在 `_classify_inter_chunk()` 中增加对新分片 manifest `process_boundary_before_first_frame: True` 的识别；若存在该标记，确认两分片跨越进程启动，判定为 `EXPLICIT_SEQUENCE_GAP`；同一进程内后续发生的未标记重连依然严格判定为 `UNMARKED_RECONNECT`。 |
| V5 重连投影适配 | [`service/acceptance_v5_reconnect.py`](../../src/binance_market_data_recorder/service/acceptance_v5_reconnect.py) 中的 `manifest_projection()` 投影白名单。 | 在 `manifest_projection()` 中保留并传递可选的 `process_boundary_before_first_frame` 字段，确保重连审计与验收链路正常接收。 |

## 再次独立复核与接续修正

复核基点：`main` / `5afcb40b8a3b8593d6cc72b34f8c69a4182acd43`，初始工作区干净。

### 已确认完成的主体

- 启动和无数据停机均不创建 Raw 空分片或额外边界文件；`SERVICE_STARTED` 使用现有全局 Catalog 事件。
- 每个 `StreamSpool` 首个非空分片设置 `process_boundary_before_first_frame=true`，后续分片省略；网络断连的真实边界证据继续保留。
- 标记在 SEALING transition evidence 中提交，既有两处封存崩溃窗口和 direct/recovery 重试均保留。SEALING 前崩溃仍使用现有 ACTIVE partial 恢复行为；本轮没有增加额外边界持久化协议。
- Raw v1 framing 未修改，实时路径没有增加 `.zst` 回读或后台重验。

### 发现的问题和最小修复

原 `_classify_inter_chunk()` 在遇到旧连接单帧 `sequence_gap` 时会提前返回 `UNKNOWN`，即使新分片已提供明确的进程启动标记。实际 V5 投影因此报 `unknown_reconnect`，与 M2.2 的显式启动边界语义冲突。

现将新分片 `process_boundary_before_first_frame is True` 的判断前移，以其证明这个明确的分片前边界。标记只作用于新首分片，不从旧分片借用，也不用于放行分片内部的连接跳变。没有启动标记时，原有 `UNKNOWN` / `UNMARKED_RECONNECT` 判定保持不变。

将 HEAD 原分类器通过 `git show HEAD:src/binance_market_data_recorder/audit/reconnect_boundaries.py` 载入独立测试进程，再运行下列两项参数化测试：**2 failed / 2 passed**；失败分别为 `UNKNOWN != EXPLICIT_SEQUENCE_GAP` 和意外的 `unknown_reconnect`。当前实现全部通过：

- `test_inter_chunk_classification_with_process_boundary`
- `test_delayed_stream_reconnect_projection_without_empty_chunks`
