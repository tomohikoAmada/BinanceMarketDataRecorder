# M3.2 独立复核与接续验收（2026-11-03）

## 结论与范围

原提交 `9495487` 的全量离线测试可以复现通过，但原“全部独立验收通过”的证据还不充分：K 线用例未走自动调度和完整落盘链路，WAL 用例未覆盖仅剩孤立 `.partial`，压测文档数值与提交的 JSON 不一致。本次补齐测试、重新测量并校正文档后，M3.2 完成。

本次只修改测试、压测证据和交接文档，`src/` 与 `9495487` 一致；没有增加生产封存回读、后台校验或新防御层。M3.3 构建冻结和 M4 VPS 验收仍是后续任务。

## 原交付核查

1. **原全量回归成立**：复跑原测试得到 `2548 passed, 24 skipped, 5 deselected, 13 warnings in 209.47s`。Ruff、strict mypy、M0 和 Go Raw golden 同样通过。
2. **K 线“端到端”声明过强**：原用例直接调用 `envelope_factory`、生命周期函数和 `_run_kline_backfill()`。两个 WS envelope 没有进入接收队列和 Raw Writer；最终序列来自内存对象，REST 分片也未关闭封存及读回。因此不能证明正常调度器实际触发补采、停机后 Raw 序列完整。`receive_time >= 125s` 也不足以约束实际 REST 接收时间。
3. **WAL 覆盖不完整**：原 6 个组合都已生成 `.zst + .json`；可选 `.partial` 是同一封存分片的重复副本。它们覆盖前滚与重复文件清理，但不覆盖 Catalog 登记回滚后仅剩未封存孤立 partial 的恢复。
4. **压测证据不一致**：原文档写入/扫描为 `54.868s / 17.006s`，RSS 为 `64.62 MiB`；原提交 JSON 实际为 `56.1349s / 17.2725s / 196.6094 MiB`。此外测试默认覆盖固定日期的报告，使后续执行可悄悄替换验收数据。`ru_maxrss` 是整个 pytest 进程生命周期的峰值，不是 Writer 的独立内存采样。

## 接续修改与故障验证

[`tests/integration/test_m3_2_fault_recovery.py`](../../tests/integration/test_m3_2_fault_recovery.py) 现有 **9 项**专项测试：

- **已封存分片 WAL 回滚，6 项**：保留 `missing / ACTIVE / SEALING × 有/无重复 partial` 的真实子进程 SIGKILL、WAL 尾部事务截断矩阵。显式确认 `WAL + NORMAL`；恢复到 `SEALED` 后，用现有 Raw 读取器验证唯一分片及原始 envelope，保留重复恢复幂等性和 12 秒 `UNKNOWN` 连续性断言。
- **仅剩孤立 partial，2 项**：Catalog 分片登记事务丢失，磁盘分别只剩完整 partial 或带 2 字节不完整帧前缀的 partial。启动分别恢复为 `ACTIVE / RECOVERED`，完整帧通过 CRC 扫描，字节与故障前有效前缀一致。没有生成 `.zst` 或完整区间 manifest，重复恢复不改写有效数据。
- **K 线跨整点自动补采，1 项**：使用真实 `SelectedAssetCapture.run()`、`ProductCapture.run()`、公共 WS 接收/重连、共享请求预算、REST 调度、Spool/Writer 和正常停机封存。只替换外部 WebSocket、REST 响应和 coverage 模块的场景墙钟；不直接调用补采函数。
  - 收到第 0 根收盘 bar；在相对 `110s` 注入 socket `OSError`，在 `125s` 重连，跨过 `119.999s` 收盘边界。
  - 下一根 WS bar 发送前，等待正常调度器完成唯一一次 REST 补采；断言请求窗口正是 `[60_000, 119_999]`（相对测试基准分钟）。
  - REST 保留真实系统接收时间，落在实际请求调用与测试结束之间；仅场景生命周期时间快进，没有用 1970 年时间下界代替真实接收时钟断言。
  - 正常停机后，从实际 `.zst + .json` 恢复恰好 3 个 Raw envelope：两份 WS 原始 bytes、两个连接 ID、一份带 `closed_bar_backfill` 的有效 REST 记录。该标记与原有 REST provenance flags 并存。
  - 合并解码后的开盘时间严格为 `[0, 60_000, 120_000]`（相对基准），没有重复或漏收，且无遗留 partial。此闭合 bar 数据序列不等于 WS 传输没有中断，原有断线证据继续保留。
