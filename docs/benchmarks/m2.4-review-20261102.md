2. **`Catalog` 超大单文件按领域子模块化拆分**：
   - 将 5,203 行的 `storage/catalog.py` 拆分为 `storage/catalog/` 包（包含 8 个子模块），对外保持 100% 向后兼容导入接口。
3. **平台与指标外围模块懒加载**：

   - `metrics/__init__.py` 中对 `DailyReporter` 实行动态 `__getattr__` 懒加载，避免采集热路径导入 `MetricsRecorder` 时误触 `report.py`。

### 2. CLI 懒加载与测试插桩兼容架构

在 `cli.py` 中引入延迟导入注册表与动态属性解析：
```python
_LAZY_MODULE_EXPORTS: dict[str, tuple[str, str]] = { ... }

def __getattr__(name: str) -> Any:
    if name in _LAZY_MODULE_EXPORTS:
        mod_name, attr_name = _LAZY_MODULE_EXPORTS[name]
        module = importlib.import_module(mod_name, package=__package__)
        return getattr(module, attr_name)
    raise AttributeError(f"module {__name__!r} has no attribute {name!r}")

def _sym(name: str) -> Any:
    """Resolve a CLI symbol from monkeypatched module globals or lazy imports."""
    mod_dict = sys.modules[__name__].__dict__
    if name in mod_dict:
        return mod_dict[name]
    return __getattr__(name)
```
- **守护进程与被动子命令执行**：`_sym("...")` 从未触发未用到的重型模块加载，`sys.modules` 中保持零污染。
- **现有自动化测试兼容**：当测试执行 `monkeypatch.setattr(cli, "load_deployment_identity", mock)` 时，pytest 首先调用 `getattr(cli, "load_deployment_identity")`，通过 `__getattr__` 获得原始定义；随后写入 `cli.__dict__`。子命令内部调用 `_sym("load_deployment_identity")` 时优先命中 `cli.__dict__` 中的 mock，完美保证测试插桩行为不变。

## 过程中发现的问题与修正

1. **`metrics/__init__.py` 导入链穿透问题**：
   - *现象*：测试发现即使 `cli.py` 内部无直接引用，只要导入 `collector.coverage`，就会意外加载 `metrics.report`。
   - *定位*：`collector/coverage.py` 导入了 `from ..metrics.recorder import MetricsRecorder`，触发了 `metrics/__init__.py` 的执行，而原 `metrics/__init__.py` 在顶层无条件执行了 `from .report import DailyReporter`。
   - *修正*：在 `metrics/__init__.py` 中采用相同的 PEP 562 `__getattr__` 懒加载机制导出 `DailyReporter`，彻底切断热路径对重型报告模块的依赖。
2. **`cli` 模块动态插桩测试兼容性**：
   - *现象*：初版将局部导入直接写在子命令分支内（例如 `from .service.deployment_identity import load_deployment_identity`），导致 `tests/unit/test_acceptance_v5_cli.py` 和 `test_launchd_service.py` 报错 `AttributeError`，且局部变量覆盖了测试预先 monkeypatch 在 `cli` 上的 mock。
   - *修正*：构建全局 `_LAZY_MODULE_EXPORTS` 与 `_sym()` 解析器，兼顾了 PEP 562 属性查找与测试 monkeypatch 覆盖语义。
3. **跨模块相对导入层级调整**：
   - *现象*：原 `storage/catalog.py` 内部的 `from .acceptance_delta import ...` 在移入 `storage/catalog/` 目录后发生层级偏移。
   - *修正*：修正为 `from ..acceptance_delta import ...`，并在 `CatalogBase` 中补齐 mixin 之间依赖的类型存根方法。
