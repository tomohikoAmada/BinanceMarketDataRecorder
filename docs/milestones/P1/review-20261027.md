## R1：退役标记与下一次recv之间存在竞态（高优先级）

位置：[共享控制](../../../src/binance_market_data_recorder/binance/websocket_common.py#L81)、[Spot循环](../../../src/binance_market_data_recorder/binance/spot/websocket.py#L718)、[USD-M循环](../../../src/binance_market_data_recorder/binance/usdm/websocket.py#L849)。

接收循环先检查`control.retirement`，再`await asyncio.sleep(0)`。轮换到期或Spot关闭通知在这个让出调度的时刻到达时，共享控制发现`waiting_for_frame == false`，设置retirement并直接等待接收任务。任务恢复后没有重新检查retirement，进入下一次recv；若缓冲恰好为空，就等不到新消息。控制方已经退出对stop / writer的组合等待，所以随后stop也不能使这个等待结束。稀疏数据流的计划轮换、服务器关闭处理及正常停机可能被拖住；它不需要磁盘故障或异常网络数据才能触发。
