`setuptools>=75,<82`. Development-only dependencies are `pytest>=8.3,<10`,

## Excluded scope and known limitations

M1 makes no Binance request and contains no Binance SDK, WebSocket, REST,
Collector, raw writer, Catalog, external archive, launchd service, GUI, account,
credential, strategy, backtest, or trading implementation. The CLI is a
synchronous skeleton; it does not create the data directory. Platform doctor
checks the nearest existing parent's current access but does not perform a
write/fsync/readback probe, which belongs to the relevant storage milestone.
Git commit discovery is best-effort and reports `unknown` outside a Git checkout
unless `BINANCE_MARKET_RECORDER_GIT_COMMIT` is injected at build/deployment time.

## Compatibility and rollback

There is no market-data compatibility impact: no Raw, Catalog, Manifest,
normalized, or Replay artifacts exist. M1 establishes configuration and CLI
contracts at package version 0.1.0. Rollback is a revert of the single M1 commit;
M0 through M0.2 documents remain usable and no production state needs migration.
