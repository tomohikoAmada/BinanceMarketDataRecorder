## Named policy

`VPS_PRODUCTION_V1` has profile ID `vps-production-v1` and is valid only when
`scope_id == "internal"`. It is never selected from host, platform,
filesystem-size, cloud metadata, systemd, environment, TOML, or CLI state.

Absolute binary-GiB thresholds use inclusive comparisons:

```text
WARNING       18 * 1024**3 = 19327352832 bytes
CRITICAL      14 * 1024**3 = 15032385536 bytes
EMERGENCY     12 * 1024**3 = 12884901888 bytes
HARD_RESERVE  10 * 1024**3 = 10737418240 bytes
```

All ETA evidence targets only the fixed 10 GiB hard reserve. Existing M11
1h/6h/24h/7d windows, median calculations, and
`MAX_AVAILABLE_WINDOW_MEDIAN` selection are reused. ETA classification uses
integer UTC nanoseconds with inclusive 7-day, 72-hour, and 24-hour boundaries.
`REACHED` maps to `HARD_RESERVE`; `INSUFFICIENT_DATA` maps to `WARNING`; and
`NOT_APPROACHING`/`BEYOND_SUPPORTED_RANGE` do not escalate.

## Boundaries preserved

- Generic M11 remains the default. `threshold_bytes()`, `space_severity()`,
  `hard_reserve_bytes()`, window helpers, raw samples, generic alert
  persistence, and status meanings are unchanged.
- `storage-forecast.v1` remains backward compatible. Explicit VPS forecasts
  add `capacity_profile`, `capacity_state`, and `hard_reserve_eta` while the
  historical `status`, `threshold_bytes`, `eta`, and `net_growth` retain their
  M11 meanings.
- No Catalog schema/migration, runtime/config/CLI/status/metrics/systemd,
  Raw/EventEnvelope, recovery, or remote archive changes were made.
- The selected rate remains filesystem free-space decline, including
  co-resident processes and archive release; no cause attribution is claimed.
- ETA emergency evidence runs pre-actions only. Collector stop requires the
  actual observed free bytes to be at or below 10 GiB. No unarchived Raw
  deletion or remote authorization is performed by the capacity policy.
- `M22_7A_CODE_AUDIT_P1_001=CLOSED`: repeated hard-reserve invocation reruns
  `seal_active()` and `stop_collectors()`, while retaining exactly one stop
  event and no duplicate gap.
