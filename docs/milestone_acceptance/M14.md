## Architecture decisions

ADR-0019 makes launchd responsible for the service process and restart policy,
while the service owns Collector isolation and graceful sealing. The OS process
lock prevents two unrelated writers but deliberately permits M13 blue/green
instances inside the one owner process. `KeepAlive.SuccessfulExit=false`
restarts crashes without forcing intentional zero exits into a loop.

Because no author domain is established in repository evidence, M14 does not
invent one. An operator must provide and attest to the label namespace. Sleep
continuity is evidence-based, not promised: NSWorkspace is primary, clock
discontinuity is explicitly an inference, and optional caffeinate only blocks
idle system sleep while macOS policy permits.

## Known limitations

V1 starts only after user login, not before login. A booted Mac with no logged-in
user does not collect. `prevent_sleep` cannot defeat lid-close, explicit sleep,
shutdown, battery loss, or system thermal/power policy. The heartbeat's RSS is
peak RSS from the standard-library platform API, not an instantaneous sample.

The operator must supply a genuinely controlled service namespace; the CLI can
validate syntax and forbidden ownership implications but cannot independently
prove domain ownership. Stop uses `bootout` for the current login session;
start re-bootstraps it, and a future login loads the retained plist. Automatic
blue/green deployment orchestration across installed package versions remains
an operator workflow around the M13 library rather than a GUI.

## Data compatibility and rollback

M14 does not change EventEnvelope, Raw framing, payload bytes, chunk manifests,
archive artifacts, normalized data, or external target contracts. Catalog uses
the existing additive `operational_events` table for service and sleep evidence.
New local control files are `state/service.lock`,
`state/service_state.json`, `state/launchagent.json`, the selected user plist,
and internal stdout/stderr logs.

Rollback bootouts/uninstalls the selected user agent, sends SIGTERM to a manual
service, releases scoped caffeinate, and restores manual Collector launch.
Preserve state/event evidence, Raw, Catalog, reports, manifests, archive
registrations, and all data artifacts. No power preference requires restoration
because M14 never changes one.
