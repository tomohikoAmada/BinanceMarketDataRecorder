## Reproduction

Before implementation, the real-EventEnvelope-shaped offline parser regression
reported nine failures. Spot `exchange_info` and each of the six USD-M
5-minute stream cases failed with `unsupported Raw stream`; the empty and
same-period semantic-identity cases failed at the same support boundary.
Changing only `SUPPORTED_STREAMS` was insufficient because the streams also
needed market-aware schemas, field validation, multi-record expansion and
semantic identities.

## Accepted contract

- Spot and USD-M `exchange_info` have distinct v1 field schemas; existing USD-M
  field order and meaning are unchanged.
- Each 5-minute response record produces one row whose semantic identity is
  based on market, stream, symbol/pair and exchange period timestamp.
- Decimal values remain exact strings.
- Same-identity/same-content observations deduplicate; same-identity/different-
  content variants remain with explicit identity-conflict evidence.
- Empty responses are explicit observations identified by logical request
  range and canonical model hash, without a fabricated timestamp.
- Existing normalized-dataset.v1 common columns and old stream schemas remain
  compatible.

Historical and Live datasets are not automatically joined. There is no
historical L2. Continuous 72-hour and 168-hour acceptance remains unexecuted.
