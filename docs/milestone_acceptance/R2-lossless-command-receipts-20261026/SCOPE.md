# Lossless command-receipt adapter, unbound LOCAL component

Definition-only adapter for the future metadata reader. A frozen caller supplies an exact read-only argv allowlist, canonical interpreter and separately qualified owned-command runner; this adapter does not recognize arbitrary command strings as safe. It preserves all five raw byte fields and the complete keeper/inventory metadata before parsing stdout; UTF8/JSON/JSONL errors remain separate, later valid JSONL rows survive. Nonzero, timeout, missing versus empty stream and exceptional provider prefixes stay distinct. Exact leased success and matching argv are process protocol facts only, never owner trust/readiness/T0.

The accepted V3 owned_command.py ef2f8882 is copied byte-for-byte and unchanged. The provided16 cases include actual disposable LOCAL macOS POSIX metadata commands and explicitly labelled provider-response faults; no service, journal, VPS, Raw or production action occurred. This does not repeat V3 warm/group tests and grants no real Linux/runuser/BOOTTIME/import/latency credit. Source20e57, all four V3 runtime subjects, failedP3/runtime/guard194e and all existing data remain unchanged.

Execution/cleanup bounds are provided by that leased runner; output-memory and outer reader/SSH/global bounds remain future integration gates. No arbitrary OOM survival or escaped-descendant guarantee. The adapter assumes the exact qualified runner's structured receipt shape; invalid providers are diagnostic faults, not qualifying sources. Byte custody is authoritative; parsed views are non-authoritative and bounded1..256 depth. No generated reader/invocation selector/owner-start+commit+postcommit consumer/17-runtime15-safe-import operator/Linux/new scope/copy/ARM/launch qualification exists. This adapter is an incremental implementation of the accepted integration design, not a new design or a completed whole reader. Independent exact adapter review remains required.
