# M21.0 Engineering Candidate — Archive Drain and Soak Sampling

## Status

**ENGINEERING CANDIDATE — PR REVIEW PENDING**

## Scope

M21.0 prepares the automation infrastructure for M21 long-term soak testing.
It does NOT begin the 72-hour or 168-hour test. It adds:

1. Bounded, re-entrant archive drain with cross-process lock
2. Archive companion systemd service/timer
3. Lightweight M21 soak sampling (single time-point observation)
4. Soak sampling companion systemd service/timer

## Not included

- No production deployment of archive timer
- No production deployment of soak timer
- No bulk archive drain of production backlog
- No 72-hour test start
- No 168-hour test start
