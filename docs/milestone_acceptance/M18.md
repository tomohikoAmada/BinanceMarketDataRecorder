## Public-market smoke

The opt-in M18 test ran Spot and USD-M BTCUSDT core Collectors together for 300
seconds in pytest's independent temporary data root. It used only unsigned
public endpoints. No side-data task, account, credential, or order interface
was used.

Final passing evidence:

| Market | diff depth | aggregate trade | book ticker | snapshots |
| --- | ---: | ---: | ---: | ---: |
| Spot | 2,980 | 2,074 | 16,186 | 2 |
| USD-M perpetual | 2,937 | 1,925 | 54,022 | 2 |

Both readiness snapshots had all three streams connected and persisted,
snapshot persisted, order book synchronized, no failure, and `ready=true`.
Thirty-two sealed chunks passed stored-size, stored-SHA-256, and decompressed
logical-SHA-256 validation. Manifests and Catalog counts agreed. Graceful stop

The first 300-second attempt correctly failed because USD-M had not
synchronized. Raw showed that the snapshot arrived before the first usable
Depth event. That failure was not counted as acceptance; it led to the first
review fix below, and the complete 300-second test was repeated successfully.

## Focused safety review

Reviewed boundaries:

- Depth bootstrap/continuity and visible gaps;
- Spot snapshot pacing, 429/418 containment, and bounded retry;
- bounded receipt, bootstrap, and spool queues;
- cancellation, graceful shutdown, and task collection;
- Raw scan/truncation/quarantine and seal verification;
- manifest/Catalog state transitions;
- copy/readback/hash/commit-before-delete ordering;
- registered-root containment and symbolic-link rejection;
- external disappearance/recovery;
- LaunchAgent install/start/stop/uninstall and data retention.

Two deterministic defects were found and fixed:

1. A normal USD-M active instance stopped taking snapshots after the first
   snapshot failed to bridge; only a blue/green candidate retried. Active and
   candidate instances now both retry with the existing bounded exponential
   backoff. A regression test proves an old first snapshot followed by a
   bridgeable second snapshot becomes ready.
2. LaunchAgent rendering resolved the virtual-environment Python symlink to
   the base interpreter, which could load another installed Recorder version.
   It now preserves the absolute virtual-environment executable path. A
   regression test proves the symlink remains in the plist, and the installed
   wheel runtime proved the exact preview Collector version.

The USD-M shutdown path was also corrected so an already persisted snapshot
does not become a false “snapshot never captured” error when shutdown occurs
during a bounded bridge retry. Readiness remains false until a real bridge.
The LaunchAgent regression suite additionally proves uninstall cannot remove
a sealed-data sentinel or the Catalog.

No new framework, exchange abstraction, GUI, strategy, backtest, account, or
trading implementation was introduced.
